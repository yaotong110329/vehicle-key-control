# 交付驗收清單

此清單用於指定 Windows Edge、固定 `http://localhost:8080/` 與真實 IndexedDB 的最後驗收。

## 初始化

- [ ] 以 `start.bat` 啟動，Edge 開啟 `http://localhost:8080/`。
- [ ] 首次資料庫建立 001、002、003、004 四把鑰匙。
- [ ] 設定頁顯示預設勤務與張OO、曾OO、王OO、李OO。

## 主要流程

- [ ] 取用 001，只選勤務，確認按鈕可用且卡片變成使用中。
- [ ] 編輯 001 補填人員，確認原始取用時間不變。
- [ ] 直接按「鑰匙歸還」，確認不跳第二次確認、卡片恢復在隊並出現 Toast。
- [ ] 在歷史紀錄確認勤務、人員、取用與歸還時間正確。
- [ ] 取用 002，只填補充說明，確認仍可完成。
- [ ] 取用 003，測試單次自訂勤務，確認不會加入勤務管理清單。

## 設定與匯入

- [ ] 在設定頁按「匯出備份」，確認下載 JSON 檔可正常保存。
- [ ] 使用「匯入備份」選擇 JSON，確認預覽筆數正確，取消不會改變目前資料。
- [ ] 確認有效備份後還原，重新整理並確認鑰匙、使用中與歷史資料一致。
- [ ] 修改鑰匙名稱，確認主畫面更新且既有歷史快照不變。
- [ ] 使用中鑰匙刪除時被阻止；歸還後可刪除。
- [ ] 修改勤務／人員名稱，確認既有使用中與歷史快照不被回寫。
- [ ] 從 Excel 複製單欄、標題列、Tab 多欄、CRLF 與空白列，測試人員及勤務匯入預覽。
- [ ] 確認匯入只新增、不覆蓋、不重複，且順序追加在清單最後。
- [ ] 在介面設定修改系統標題、總覽標題並上傳／移除 Logo，重新整理後確認仍保留。

## 多頁籤與持久性

- [ ] 同一 Edge 設定檔開啟兩個 localhost 頁籤。
- [ ] 在頁籤 A 取用或歸還，確認頁籤 B 自動更新。
- [ ] 兩個頁籤同時取用同一把鑰匙，確認只有一方成功且另一方收到衝突提示。
- [ ] 關閉 Edge 後重新啟動，確認使用中及歷史資料仍存在。

## 鍵盤與可及性

- [ ] 由按鈕開啟 Modal 後，焦點落在第一個可操作欄位。
- [ ] 以 Tab、Enter、Space 完成主要取用、設定與匯入操作。
- [ ] 以 Esc 關閉非忙碌 Modal，關閉後焦點回到原開啟按鈕。
- [ ] 確認錯誤訊息、Toast、狀態 Badge 在桌面尺寸下清楚可辨識。

## Tauri EXE

- [ ] 在可用 Rust／Tauri 工具的 Windows 建置機執行 `build-exe.bat`。
- [ ] 確認 NSIS 安裝檔可在沒有系統管理員權限的帳戶中安裝到 `%LOCALAPPDATA%`。
- [ ] 目標電腦沒有 Internet 時，確認離線 WebView2 安裝資源可完成安裝。
- [ ] EXE 啟動時視窗自動最大化，且仍保留 Windows 標題列與關閉按鈕。
- [ ] 從瀏覽器版匯出 JSON，於 EXE 匯入後確認資料、使用中紀錄、歷史紀錄與介面設定一致。
